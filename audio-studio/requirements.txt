# audio-studio — the exact dependency set this studio was built and verified on
# ---------------------------------------------------------------------------
#
# Why this file exists: `pyproject.toml` splits the dependencies into extras
# (`.[asr]`, `.[align]`, `.[llm]`, `.[dev]`) and only sets *lower* bounds on
# them. That is fine for a project that is already installed, and it is what
# broke on a fresh machine — `faster-whisper>=1.0.3` happily pulls a `PyAV`
# release newer than the one `faster-whisper`'s own code supports. The pins
# below are the versions actually installed in this studio's `.venv`, read off
# `pip freeze`, not chosen from a benchmark table.
#
# Use (from this directory — the same one `pyproject.toml` lives in):
#
#     python -m venv .venv
#     source .venv/Scripts/activate          # Windows / Git Bash
#     pip install -r requirements.txt        # everything below
#     pip install -e .                       # the package + the `audio-studio` command
#
# The `-e .` step is separate on purpose: this file is run from `audio-studio/`,
# but if someone runs `pip install -r` from the repository root it must still be
# a pure dependency install and not try to build the repository root as a package.
#
# Python version: 3.11.0, the interpreter this set was resolved against. Every
# binary pin below was checked to install on 3.11 **and** 3.12 **and** 3.13 too
# (the wheels are `abi3`, or ship per-version builds), so a machine on a newer
# Python is fine. See the note on `av` — that is the one that is not obvious.
#
# The API key for the optional `[llm]` validation pass comes from the process
# environment, with `.env` loaded underneath it — the file in this folder, or in the
# working directory and any of its four nearest ancestors. `.env.example` ships beside
# this file and holds the shape (`../.env.example` is the same template, for a run
# started from the suite root); `audio_studio/env.py` has the exact rules. Nothing else
# is needed to install, and no key is needed at all unless you ask for `--validate llm`.
# `python -m audio_studio doctor` prints the packages and passes it can actually see.

# --- asr: real transcription (faster-whisper / CTranslate2 backend) ---------
faster-whisper==1.2.1
numpy==2.4.6
# `av` is pulled in transitively by `faster-whisper`, which declares only
# `av>=11` — no upper bound. It is pinned here on purpose, because it is the one
# dependency whose *major* version silently breaks this studio:
#
#   faster_whisper/audio.py calls av.open(..., metadata_errors="ignore").
#   PyAV removed that keyword argument in 19.0.0, so on av>=19 that call raises
#   TypeError, every decoder fallback after it fails, and the user is shown
#
#       cannot decode audio: install the 'asr' extra ... or put ffmpeg on PATH
#
#   which blames a missing `ffmpeg` binary for what is actually an incompatible
#   library version. Nothing in the message points at `av`.
#
#   The installed version therefore decides whether decoding works at all, and
#   it is selected by accident: av 18.x requires Python >=3.11, av 19.x requires
#   Python >=3.12. This environment is Python 3.11, so pip picked 18.1.0 and the
#   studio never showed the problem; a machine on Python 3.12+ gets av 19 and
#   cannot decode anything, from a clean `pip install -e ".[asr]"`.
#
#   `av==18.1.0` ships an `abi3` wheel, which was verified to resolve to
#   av-18.1.0-cp311-abi3 specifically for target Pythons 3.11, 3.12 and 3.13 —
#   so this pin is correct on all of them, not just on the 3.11 box it came from.
av==18.1.0

# --- align: forced alignment (wav2vec2 CTC, re-times each word) -------------
# The CPU wheel index is required for the `+cpu` build, which is ~10x smaller
# than the default build that drags in ~2.5 GB of CUDA libraries for a machine
# that has no GPU. On a CUDA machine, drop the line below and the `+cpu` suffix
# (use `torch==2.14.1`) and every other pin stays valid.
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.14.1+cpu
transformers==5.18.0

# --- llm: optional transcript validation through a hosted model -------------
google-genai==2.26.0
httpx==0.28.1

# --- dev: the test suite ---------------------------------------------------
pytest==9.1.1


# ---------------------------------------------------------------------------
# Model weights — downloaded lazily on first use, NOT installed by pip
# ---------------------------------------------------------------------------
# These live in the Hugging Face cache outside this repository, so there is no
# version to declare above - but they are version-locked all the same, and in the
# one place that can enforce it: `audio_studio/models.py` records the commit each
# model was verified at (`MODELS[...]["revision"]`, plus `ALIGN_REVISION` for the
# aligner) and both the transcriber and the aligner pass it to the loader. Without
# that pin, `small` means "whatever Systran/faster-whisper-small's `main` points at
# on the day this machine first ran" - which is how two laptops install a month
# apart and disagree about the same recording with nothing on screen to explain it.
#
#   short name         repository                                weights  preset
#   small              Systran/faster-whisper-small               464 MB   `balanced` (default)
#   base               Systran/faster-whisper-base                142 MB   `fast`
#   medium             Systran/faster-whisper-medium              1.7 GB   `accurate`
#   distil-large-v3    Systran/faster-distil-whisper-large-v3     1.5 GB   `best` (opt-in)
#   (aligner)          facebook/wav2vec2-base-960h                361 MB   forced alignment
#
# `python -m audio_studio doctor` prints the pin beside each preset, and every
# transcript and alignment records it in its provenance block, so two machines can
# be compared rather than guessed at. The `[llm]` validator is hosted and downloads
# nothing; its model is `gemini-3.5-flash-lite` by default.
