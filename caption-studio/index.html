Transcribe server unchecked

The Python studio beside this one, which measures word timings from the audio instead of inheriting them. Start it with python -m audio_studio serve. Its output lands in the AI source below — so a TRUTH subtitle file still corrects the spelling exactly as before, while the timings are now measured rather than borrowed.
Opens a run's captions in the editor as they were written — no second transcription. Load the recording itself under Sources to hear it against them.
The words the song actually has. Give them to the studio and the text comes from this file while the timing still comes from the audio, so nothing is guessed — added lines are timed by interpolation and then re-timed by the aligner. A file that is not this recording is refused rather than applied. (The TRUTH source further down is a different pass: it fixes spelling locally. The same file can be used in both.) This is the field that keeps a sung transcript from drifting: without it the transcriber decides both the words and the timing, and on a song it can be a beat out by the second chorus.

Export —

Export video… opens the export window, where the container, resolution, frame rate, quality and bitrates are all set — and where choosing a resolution tunes the rest for you. The encode renders every frame offline with the browser's own encoder, so it is not tied to real time, the preview stays usable while it runs, and the cuts you made on the timeline are honoured. Sound comes from the audio file loaded under Sources (the master track). The other buttons write the caption data itself: the project, the Veed master JSON, and plain SRT / VTT that any other editor can read.
